Proposed auto-tagging reference set

This is an operator approval proposal, not an approved ground truth. The classifier reports precision and recall against it with the proposed status visible. The operator can amend individual assignments and glossary terms before approval.

Sample

The item data contains 60 Agent Studio cards and 20 Dossiers. Cards were sampled from the live Task API on 25 September 2026 across active, completed, and archive states and creation months May through September 2026. Dossiers came from repository workbench.json descriptors and include current and historical statuses. Each row preserves its title, bounded body or summary, lifecycle state, expected area and facet ids, source, and a short rationale.

Vocabulary

The proposed glossary data derives terms from the AGT-W55 area descriptions and the corresponding Dossier vocabulary. It covers all ten product areas. Runtime classification uses these terms only when an official area glossary is empty. Both files carry status: proposed and approvedBy: null.

Measurement

Tier 1 uses a Sonnet-class route at low thinking. The evaluator compares its closed-registry predictions with the 80 expected tag sets. If precision is below 0.9, tier 2 runs at high thinking and classification selects it automatically. The backfill dry-run report shows precision and recall for the measured tiers, area counts, and low-confidence proposals. The numbers describe agreement with this proposed sample until the operator approves it.

Approval decision

The linked decision card asks the operator to approve or amend this set and the proposed glossaries. Approval records the operator identity and date in the data; it does not silently change the expected tags. See the AGT-2804 delivery report for the card link.
