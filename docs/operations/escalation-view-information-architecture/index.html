Escalation view information architecture

An escalated task should state the blocker once, identify the failed step once, and leave the Result view to explain the run. The current detail view repeats the failure while hiding the actual problem.

Recommendation

Make the escalation header the sole owner of the actual blocker and the human-decision state. Remove the terminal escalation strip and GAP from Pipeline on escalated cards. Remove the Pipeline failure case badge from Result on escalated cards. Keep the CORE AGENT WORK ATTENTION marker because it identifies the failed locus rather than restating the task outcome.

03Alternatives considered

Selected

The header owns the blocker. It is the only location visible regardless of the active tab and already owns the operator actions. The exact recorded reason is promoted without inventing a second summary.

Not selected

Result owns the GAP. This would make Result self-contained, but the operator could still arrive on Overview and see a content-free decision header. It also separates the reason from the actions that resolve it.

Rejected

Keep every surface and improve their copy. Better wording does not cure duplication. Three red outcome statements still compete, and Pipeline still explains a task-level decision above its step evidence.

04Target information architecture

Each fact has one owner. Related facts may appear together, but the same outcome or blocker text is not repeated across the header, Pipeline, and Result.

InformationSingle ownerRendering contract
Actual blocker / GAPEscalation headerOne readable summary line under Escalation. Source priority: recorded status-stub reason, structured steering reason, first structured open finding, then the explicit fallback No blocker summary was recorded. Do not synthesize a plausible cause.
Human decision state and actionsEscalation headerOne Needs decision status with Continue, Accept as-is, and Abort. Remove Human decision required from the descriptive line.
Review and delivery contextEscalation header disclosure/bodyShow only facts that exist. Zero review rounds, grade not recorded, zero findings, and empty delivery context do not displace the blocker.
Failure locusPipelineKeep CORE AGENT WORK ATTENTION, its concern count, and the failed Agent execution row. Remove the terminal completion-loop escalation chip and GAP from this section.
Run goal and stop boundaryResultGOAL and WHERE IT STOPPED are flat sibling rows. GOAL is neutral. WHERE IT STOPPED uses a calm full-row red tint with no colored left bar, border, radius, or nested panel. It describes the execution boundary, not a second copy of the header blocker; omit it when no distinct boundary was recorded.
Result evidence and metricsResultKeep real metrics, detail Markdown, artifacts, and provenance. Suppress the task-level outcome case badge on escalated cards because the header already owns that outcome.

Consistency rule

Once a card is in the escalated terminal state, the exact GAP text appears only in the header. Timeline may retain the historical event record, but Overview and Result do not restate it as persistent chrome.

06Implementation slice plan

These are review-ready delivery boundaries, not implementation cards. Cards are created only after the operator approves this dossier.

Slice 1
Header summary projection. Extend escalation-summary.util.ts with one typed problemSummary and the documented source priority. Render it in EscalationSummaryComponent; hide empty metrics and remove the redundant Human decision required phrase. Add pure priority tests and component rendering tests.
Slice 2
Pipeline de-duplication. Prevent CompletionLoopIndicatorComponent from rendering its terminal escalated verdict and reason inside Pipeline. Preserve reopened attempt-cycle information for non-terminal work. Assert that CORE ATTENTION and the failed step remain.
Slice 3
Flat escalated Result. Suppress result-case-badge on escalated cards. Remove the outer overview card boundary and the nested blocked-row box. Render GOAL and WHERE IT STOPPED as sibling rows, using the semantic high-severity tint for the stopped row and no left accent. Do not repeat the header blocker.
Slice 4
Acceptance proof. Extend the AGT-2278-shaped Playwright fixture and real Stable probe. Cover light and dark, wide and narrow, header expanded and collapsed, a recorded blocker, a missing blocker fallback, no Result outcome badge, no terminal Pipeline strip, and retained CORE ATTENTION.

Expected code scope after approval

features/task-detail/components/escalation-summary/, features/task-timeline/components/completion-loop-indicator/, features/task-detail/components/protocol-pane/result-view/, the pure result/escalation projections, and focused unit and Playwright specs. No backend or wire-contract change is required for the observed status-stub and timeline data.
