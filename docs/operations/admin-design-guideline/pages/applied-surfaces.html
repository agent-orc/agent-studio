How to add a row

When a revamp card is reviewed and merged, the card author adds one row to this table following the pattern above. The row must include: the ISO date the review was merged, a short surface name and the canonical route, the before/after SVG schematic (inline, 240 x 90 viewBox), the applied contract in plain prose, the card key as a AGT-XXXX chip, and the state badge.

Do not remove or edit existing rows. A subsequent improvement to the same surface adds a new row below the original.
