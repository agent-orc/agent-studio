# Getting started

No GitHub Release has been published yet, so the
[product install guide](./install.md) downloads return 404 for now. Start with
the [setup guide's path table](./README.md#choose-your-path). It names one
recommended path per situation with its prerequisites. For one machine, that
is the [source-built Docker one-box](./docker.md#install-from-this-checkout).
After the stack is up, follow [your first task](./your-first-task.md).

The current one-box deployment uses the distributed Task
Server and Engine, with the BFF serving `/api/v1`; other dev-seat
routes still have the option C coverage limit recorded in the
[connector gap](./docker-compose-connector-gap.md).

Source contributors can use the [contributor setup](./contributor-setup.md).
