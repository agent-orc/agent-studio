# UI standard

## Purpose and boundary

Working material for the product-wide UI standard: pilot pages, the patterns
they establish, and the shared components behind them. A pattern recorded here
is a proposal until the owner has reviewed its pilot page; the binding rules
stay in [quality/design/](../../quality/design/README.md) and the component
vocabulary in [quality/frontend/style-guide/](../../quality/frontend/style-guide/README.md).
