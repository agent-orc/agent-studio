Runtime prompts, their consumers, and their review state

Shipped Markdown is the default. Application-wide edits create a durable override. A project can additionally replace the prompt for one pipeline step in project-settings.json.

How overrides resolve

  1. Shipped file in prompts/runtime/ is the baseline.
  2. Application override replaces that file for every project.
  3. Project pipeline override replaces the bound step prompt only for its project.
