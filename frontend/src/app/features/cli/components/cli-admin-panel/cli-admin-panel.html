Completion contracts

how each CLI signals turn completion

Each adapter's self-report: which native frame it treats as a turn finished or failed, where the per-turn usage summary is read from, and whether it is a typed adapter (structured events) or falls back to exit-based detection. Read-only by design — nothing here is configuration. It is a diagnosis tool: when completion detection misfires (as with the tool-router parser bug, AGT-2089), this is where you confirm what signal the orchestrator was actually waiting on.
