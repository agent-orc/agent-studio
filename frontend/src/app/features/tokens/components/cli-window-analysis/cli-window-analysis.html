Plausibility

Keep unlike measurement levels visibly separate.

  • Quota: provider-reported account window units.
  • Tokens: locally captured receipts attributed by stored CLI inside each quota interval.
  • Trend: workspace-wide until the timeline contract carries CLI attribution.
